Projects

Pick a project in the search box by typing @alias or pressing Tab. Without an alias, the project ID is used. A header color tints the top of the console for that project; leave it empty to keep the console default. Drag ⠿ to reorder; the project list in the search box follows this order.

Service list

Uncheck an item to hide it from search. Hidden items stay hidden after a refresh.

    Custom pages

    Choose a project, then add a name and console path or full URL (Airflow, YARN, etc.). Pages appear only for that project. Console paths get ?project= automatically; external URLs open as saved.

    When adding an external URL, allow site access if prompted to show the project's Header color strip. Already allowed sites need no further approval. Reload open custom pages after adding.
